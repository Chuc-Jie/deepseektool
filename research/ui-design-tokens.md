# 扩展 UI 视觉规范

> 适用范围：`extension/popup.*` 以及后续页面内设置面板的视觉对齐。
> 本文只描述本项目自己的设计令牌与组件规范，不记录任何外部来源。

## 1. 设计目标

- **工具感、低噪音**：信息密度适中，不用大面积高饱和色块，靠细边框与层级区分内容。
- **紧凑但不拥挤**：popup 宽度 360px，正文以 12–14px 为主，行高 1.35。
- **克制的动效**：120–180ms，位移最多 1px，不做弹跳和大幅缩放。
- **双主题一等公民**：浅色 / 深色都通过同一组令牌切换，组件不写死颜色。

## 2. 设计令牌

统一定义在 `extension/popup.css` 的 `:root`，前缀 `--ds-`。后续页面内面板复用同一组值。

### 2.1 颜色（浅色）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ds-brand` | `#1b61c9` | 主按钮、选中态、链接 |
| `--ds-brand-hover` | `#164fa8` | 主按钮 hover |
| `--ds-brand-soft` | `rgba(27, 97, 201, .10)` | 选中背景、渐变光晕 |
| `--ds-brand-subtle` | `rgba(27, 97, 201, .06)` | 更弱的背景光晕 |
| `--ds-brand-ring` | `rgba(27, 97, 201, .22)` | 键盘 focus 外环 |
| `--ds-text` | `#181d26` | 主文本 |
| `--ds-text-2` | `rgba(24, 29, 38, .78)` | 次级文本 |
| `--ds-text-3` | `rgba(24, 29, 38, .58)` | 辅助说明、版本号 |
| `--ds-text-inverse` | `#f9fcff` | 主按钮文字 |
| `--ds-surface-canvas` | `#f5f8fc` | 页面画布 |
| `--ds-surface` | `#ffffff` | 卡片、控件 |
| `--ds-surface-2` | `#f8fafc` | 次级表面、hover |
| `--ds-border` | `#e0e2e6` | 卡片/控件边框 |

语义色：成功 `#006400`、警告 `#9a6700`、危险 `#c24141`，各自配 6–10% 的同色浅底。

### 2.2 颜色（深色）

| 令牌 | 值 |
| --- | --- |
| `--ds-text` | `#eef3fb` |
| `--ds-text-2` / `--ds-text-3` | 76% / 56% 透明度 |
| `--ds-surface-canvas` | `#0f1722` |
| `--ds-surface` | `rgba(15, 23, 34, .94)` |
| `--ds-surface-2` | `rgba(21, 31, 46, .94)` |
| `--ds-border` | `rgba(216, 225, 240, .14)` |
| `--ds-border-2` | `rgba(216, 225, 240, .10)` |
| `--ds-border-strong` | `rgba(216, 225, 240, .20)` |
| `--ds-border-brand` | `rgba(92, 162, 255, .34)` |

品牌主色在深色下保持不变（白字对比度足够），只把选中态边框与浅底提亮。

### 2.3 字体

- 字族：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`
- 字号：11（说明）/ 12（标签）/ 13（正文）/ 14（品牌名）/ 16（区块标题）/ 20（页面标题）
- 字重：400 / 500 / 600
- 行高：1.2（标题）/ 1.3（紧凑）/ 1.35（正文）
- 字距：0.10px（正文小号）/ 0.16px（正文）/ 0.24px（标签、品牌名）

### 2.4 间距与圆角

- 间距梯度：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40
- 圆角：8（小控件）/ 12（按钮、导航项）/ 16（卡片）/ 24（大容器）/ 999（胶囊）

### 2.5 阴影

- `--ds-shadow-xs`：`0 0 1px rgba(0,0,0,.18), 0 1px 2px rgba(27,97,201,.16)`
- `--ds-shadow-sm`：`0 0 1px rgba(0,0,0,.18), 0 2px 6px rgba(0,0,0,.08), 0 1px 3px rgba(27,97,201,.20)`
- 默认状态尽量无阴影，只在 hover / 主按钮上使用。

### 2.6 动效

- 时长：`120ms`（颜色、边框）/ `180ms`（位移、阴影）
- 缓动：`cubic-bezier(.2, 0, 0, 1)`
- 允许的位移：`translateY(-1px)`，按下回 0
- `prefers-reduced-motion: reduce` 时关闭位移与过渡

## 3. 组件规范

### 3.1 Popup 框架

```
360px 宽，高度由内容自适应（不设固定 min-height，避免底部空白）
├─ 头部：34px 图标 + 品牌名（14px/600）+ 副标题（12px/次级），右侧版本号（11px/三级）
├─ 分割线：1px --ds-line
├─ 内容卡片：16px 圆角、14px 内边距、1px 边框
└─ 底部：11px 三级文本两段，细分割线，左右分列
```

背景使用一层极淡的右上径向光晕叠加画布色；`html` 负责画布背景，`body` 透明。
页面禁用滚动（`overflow: hidden`），窗口高度由内容决定，避免滚动条槽在右侧/底部形成透明边。

### 3.2 卡片

- 边框 `1px solid var(--ds-border)`，圆角 16px，内边距 14px
- 背景为 `--ds-surface` 与 `--ds-surface-2` 的轻微混合
- 默认无阴影；hover 时边框降为 `--ds-border-2` 并出现 `--ds-shadow-xs`
- 卡片之间间距 12px

### 3.3 按钮

- 高度 40px，圆角 12px，13px/600，字距 0.08px
- 次要按钮：表面底 + 1px 边框；hover 只改变底色与边框，不做位移（popup 空间小，避免抖动）
- 主按钮：品牌色底 + 反白文字；hover 用 `--ds-brand-hover`
- 禁用：透明度 0.45，不响应 hover
- 键盘 focus：`box-shadow: 0 0 0 3px var(--ds-ring)`，不使用默认 outline

### 3.4 状态提示

- 单行小卡片：9px 11px 内边距、10px 圆角、12px 字号
- **左侧 3px 色条**作为状态指示，颜色跟随语义色；同时保留文本，不单靠颜色表达
- 四种 tone：`busy`（中性）/ `ok` / `warn` / `error`
- 背景使用语义色的 6–7% 浅底，边框 16–17% 透明度；`aria-live="polite"` 播报变化

### 3.5 分段控件（后续设置面板使用）

- 外层胶囊：`--ds-radius-full`，2px 内边距，次级表面 + 细边框
- 选项：`padding: 5px 10px`，11–12px/600；选中项白底 + 品牌色文字 + `--ds-shadow-xs`

### 3.6 开关

- 44×24px，圆角 12px，边框 1px
- 滑块 18px 圆形，左侧 1px 内缩，选中右移 20px
- 选中背景 `--ds-brand`；focus 使用品牌色外环

### 3.7 页面内浮动操作按钮（后续使用）

- 38×38px，圆角 12px，1px 边框
- 背景用半透明表面 + `backdrop-filter: blur(4px)`
- hover 上移 1px、边框转品牌色；disabled 透明度 0.46

### 3.8 页面内设置面板（后续对齐）

- 左侧 280px 侧栏 + 右侧内容，整体最大宽度 1040px
- 侧栏导航项：12px 圆角、11px 12px 内边距、active 用品牌浅底 + 品牌边框
- 主区标题 20px/600，内容区 22px 40px 内边距
- 分区切换使用 300ms 淡入 + 5px 上移

## 4. 可访问性

- 正文与背景对比度 ≥ 4.5:1；次级文本 ≥ 3:1
- 所有可交互元素提供 `:focus-visible` 外环
- 状态不能只靠颜色表达：状态条同时有文本与圆点
- 尊重 `prefers-reduced-motion`
