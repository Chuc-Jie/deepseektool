## DeepSeek 功能增强工具箱 v4.7.0

### 一、脚本概述

本脚本为 DeepSeek Web 端提供一系列增强功能，所有管理项集成在**统一控制面板**中，设置后即时生效，无需刷新页面。

包含四大核心模块：

1. **代码块折叠**：按行数阈值自动折叠，可自定义预览行数，手动展开不受后续加载重置。
2. **表格优化与导出**：修复表格宽度问题，可选的 PNG / CSV / Markdown 导出按钮。
3. **AI 思考过程自动折叠**：自动折叠"已思考"区域，支持模拟点击和 CSS 直接折叠两种模式。
4. **对话文件夹管理**（可选精辅）：在左侧对话历史栏按「文件夹」做树形分组，会话 ⋯ 菜单直接移入/移出，收进文件夹即从原生列表隐藏；随官网浅/深色主题自适应。

> 说明：此脚本同时包含「宽屏模式」（消息区扩展到全宽）开关，以及「代码块折叠—预览行数/阈值」等多项细节设置，均在面板一页内完成。

### 二、功能详情

#### 2.1 代码块折叠
- 在代码块右上角添加"折叠/展开"按钮（含箭头图标）。
- **自动折叠阈值**：代码行数超过设定值时自动折叠（默认 20 行，设为 0 则禁用）。
- **折叠预览行数**：折叠后保留前 N 行可见（默认 0 表示完全隐藏）。
- **状态保持**：用户手动展开的代码块不会因后续对话加载而自动折叠。

#### 2.2 表格优化与导出
- **样式修复（始终生效）**：表格宽度自适应、列宽均分、圆角边框、行悬停高亮。
- **列宽策略（新增）**：三种策略可选 —「均分」所有列等宽、「自适应」按内容比例分配、「均分+保护」等宽+80px下限（超出容器自动回落自适应），控制面板可切换。
- **主题适配（新增）**：两种策略适配浅色/深色主题 —「自动适应」用半透明叠加色通吃两种模式，「双模式」为浅色/深色各自优化配色，控制面板可切换。
- **导出按钮（可开关）**：表格右下角悬浮 📸（PNG）和 📄（CSV）以及 📝（Markdown 一键复制）按钮，鼠标悬停显示。PNG 依赖 `html2canvas`；CSV 原生 UTF‑8 BOM；Markdown 保留单元格内 `code`/加粗/斜体并转义 `|`，直接复制进剪贴板。PNG 导出自动跟随当前主题配色。三种格式共用同一份「清洗副本」（PNG/CSV/MD 走 `getCleanTableClone`）。

#### 2.3 AI 思考过程自动折叠
- 自动寻找"已思考"区域并折叠，避免页面过长。
- 两种折叠模式：
  - **模拟点击**：通过点击原生箭头折叠，保持与 DeepSeek 原生交互一致。
  - **CSS 直接折叠**：关闭模拟点击后使用，直接隐藏思考内容区域。

#### 2.4 对话文件夹管理（面板开关，默认关闭）
- 在「⚙️ 脚本设置」中开启「🗂 启用文件夹分组」后，左侧对话历史栏顶部出现**文件夹面板**（[文件夹]+[＋新建]），随对话历史整体滚动（区内不再单独设内部滚动条），不破坏官网原有挂点。
- **树形就地展开**：文件夹行前的空心文件夹图标可点开/收起（展开态持久化，存入数据）；展开后其下内嵌该夹内会话行——当前正在访问的会话以主题色高亮（浅色标签态），其它可行直接点击跳转官方会话，每行右端一个「移出」按钮。
- **面板可整体折叠**：点面板头上的「文件夹」标题即可收起/展开整个文件夹列表（箭头随状态转向，折叠态同样持久化）；收纳后只留一行标题，不再占据滚动高度。
- **归档隐藏**：会话一经归入某文件夹即从官方原生历史列表自动隐藏（避免点树内会话时官方滚回原位）；原生历史始终只保留未收进文件夹的会话。
- 分组操作走原生交互：把鼠标悬停任一对话的三点菜单 →「移动到文件夹」→ 悬停即展开文件夹列表（仿 Windows 级联子菜单，自动翻侧/夹紧视口），点击文件夹即归类；也可以直接选「+ 新建文件夹…」或「移出文件夹」。
- 会话标题旁附所属文件夹的**彩色标签**（标签随深/浅主题配色）；分组数据（含展开态 `expanded`）存于独立键 `deepseek_folder_manager_data_v2`，随官网深/浅色自适应主题。
- **关闭开关**：还原全部被归档隐藏的原生会话行、移除树面板/彩色标签/注入菜单项与临时样式、清掉注入的 CSS 变量，再一次开启不影响已保存的分组。

### 三、使用说明

1. 安装脚本并访问任一 DeepSeek 对话页面。
2. 点击 **Tampermonkey / ScriptCat 菜单 → "⚙️ 脚本设置"** 打开控制面板。
3. 可调整：代码块折叠阈值与预览行数、宽屏模式、表格导出按钮开关、表格主题/列宽策略、AI 思考自动折叠及模式、对话文件夹管理开关。
4. 修改设置后**立即生效**，无需刷新。
5. 配置自动保存，下次打开页面保持。

### 四、兼容性

- 支持域名：`chat.deepseek.com`、`www.deepseek.com`、`deepseek.com`
- 依赖：`html2canvas@1.4.1`（`@require` 引入）
- 基于 DeepSeek 当前 DOM 结构编写，若页面大版本更新可能导致部分功能失效。
