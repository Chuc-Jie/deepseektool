## DeepSeek 功能增强工具箱 v5.8.0

> 面向 DeepSeek Web 端的增强用户脚本（Tampermonkey / ScriptCat 通用）。本文档面向开发者与维护者，记录模块行为、技术细节与版本历史；**安装使用、功能入口与设置项说明见 [scriptcat-description.md](scriptcat-description.md)**（即 ScriptCat 商店页描述，两者同源，改动功能时同步维护）。

### 一、脚本概述

为 DeepSeek 对话页提供统一控制面板的一站式增强：设置即时生效、无需刷新，配置自动保存。包含六大核心模块与若干附加开关：

1. **代码块折叠**：按行数阈值自动折叠，可自定义预览行数，手动展开不受后续加载重置。
2. **表格优化与导出**：列宽按内容自适应（可选智能 / 均分、铺满 / 紧凑、滚动 / 压缩、表头对齐），可选的 PNG / CSV / Markdown 导出按钮（悬浮在表格右下角之外，支持「持续显示」）。
3. **对话导出为 Markdown / JSON**（v5.0.0 新增，v5.2.0 增 JSON）：勾选消息 → 选格式（Markdown 再选内容模板）→ 下载 `.md` / `.json`；长对话自动扫描全量，9 套内容模板，JSON 逐条消息带 `role` / `content` / `reasoning` 字段，全程本地不上传。
4. **AI 思考过程自动折叠**：自动折叠「已思考」区域，支持模拟点击和 CSS 直接折叠两种模式。
5. **对话文件夹管理**（可选精辅，默认关）：左侧对话历史栏按「文件夹」做树形分组，会话 ⋯ 菜单直接移入/移出，收进文件夹即从原生列表隐藏；随官网浅/深色主题自适应。
6. **代码块导出为图片**（v5.1.0 新增）：代码块右上角「导出」按钮 → 弹窗选择样式（背景 / 窗口样式 / 代码底色 / 内边距 / 字号 / 行高 / 导出倍率 / 投影·行号 共 8 组）→ 一键导出 PNG（下载或复制图片到剪贴板），本地离屏渲染、不上传。

> 附加项：宽屏模式（三档宽度：标准 +160 / 较宽 +320 / 最宽 +480，相对官方 840px）、Ctrl+Enter 发送快捷键、表格主题/列宽多策略、代码块背景加深（默认开）等，均在控制面板一页内完成，详见下文 2.2 / 2.3 / 2.7。

### 二、功能详情

#### 2.1 代码块折叠
- 在代码块右上角添加「折叠/展开」按钮（含箭头图标）。
- **自动折叠阈值**：代码行数超过设定值时自动折叠（默认 20 行，设为 0 则禁用）。
- **折叠预览行数**：折叠后保留前 N 行可见（默认 0 表示完全隐藏）。
- **状态保持**：用户手动展开的代码块不会因后续对话加载而自动折叠。

#### 2.2 代码块外观（背景加深）
- **问题**：官网浅色主题下代码块底色为 `#F9FAFB`，与白色页面底几乎无对比、边界感极弱（作为参照，官网行内 `code` 用的是 `#EBEEF2`，比代码块本体深两档）。
- **加深开关**（默认开）：把代码块底色加深；顶部语言/工具条与代码区同色，并补 `1px` 底分隔线，消除白顶条与灰代码体的割裂。
- **加深强度**：三档可选 —「轻微」`#F3F4F6`（默认）、「中等」`#EEF1F5`、「明显」`#E9EDF2`；开关关闭时该行置灰不可点。
- **边界**：仅作用于浅色主题（`body:not(.dark)` 限定），深色主题保持官网原样；分隔线使块高仅 +1px，无布局位移。

#### 2.3 表格优化与导出
- **样式修复（始终生效）**：表格宽度自适应、列宽分配、圆角边框、行悬停高亮。
- **列宽自适应（v5.6.0 重做）**：按每个单元格的实际字体**逐节点**测量（表头 600 / 正文 400 / 行内代码等宽，并计入 `letter-spacing` 与 `<code>` 的 `padding`），得到每列「单行放下」所需宽度。预算不足时用 **max-min fair**（二分水位）分配——各列压缩程度一致、折行数接近，整表最矮；预算充足时各列先满足单行，富余**均分**，避免长表头列吃掉大半宽度。
- **四项可调**：「列宽方式」智能（推荐）/ 均分列宽 ·「表格宽度」铺满整行 / 内容紧凑 ·「列过多时」横向滚动 / 压缩进容器 ·「表头对齐」跟随内容对齐 / 水平居中。
- **主题适配**：两种可选 —「自动适应」用半透明叠加色通吃浅/深色两种模式，「双模式」为浅色/深色各自优化配色。
- **导出按钮（可开关）**：悬浮在表格**右下角之外**——内容紧凑时贴表格右边缘，铺满整行时落到消息区外；悬停表格或按钮本身即显示（穿过 12px 间隙不会闪断），「持续显示」开启后常驻。📸（PNG）、📄（CSV）、📝（Markdown 一键复制）。PNG 依赖 `html2canvas`、列宽与页面一致（保留 `<colgroup>` 并按导出宽度等比缩放）且跟随当前主题配色；CSV 原生 UTF-8 BOM；Markdown 保留单元格内 `code`/加粗/斜体并转义 `|`。三种格式共用同一份「清洗副本」（`getCleanTableClone`）。
- **导出图片圆角**（默认开，v4.11.0）：PNG 导出后在 canvas 上用 `destination-in` 把表格四角裁成**透明圆角**（关闭则四角为直角矩形，与旧版一致）；PNG 的「纸底」跟随页面深浅——浅色页面用白底、深色页面取页面实际背景色，避免深色表头压在纯白底上。另：导出的 iframe 不继承页面 `color`、页面上的 `.ds-markdown ...` 规则也不匹配，故导出会**抄取页面上表格内的实际计算样式**——单元格文字色（`th`/`td`，v4.11.0）、链接（`a` 的 color + 下划线）与行内 `code`（文字色 + 背景色，v4.11.1），深色主题下不会出现黑字压深底、默认蓝链接、灰底代码块。实现要点见 MAP.md 第 5.3 节。

#### 2.4 AI 思考过程自动折叠
- 自动寻找「已思考」区域并折叠，避免页面过长。
- 两种折叠模式：
  - **模拟点击**（默认）：通过点击原生箭头折叠，保持与 DeepSeek 原生交互一致。
  - **CSS 直接折叠**：关闭模拟点击后使用，直接隐藏思考内容区域。

#### 2.5 对话文件夹管理（面板开关，默认关闭）
- 开启「🗂 启用文件夹分组」后，左侧「对话历史」栏出现文件夹面板（[文件夹]+[＋新建]，位于原生「置顶」分组之后），随会话历史整体滚动；面板头可整体收起/展开（状态持久化）。
- **树形就地展开**：文件夹行前空心图标点开/收起（展开态持久化），展开后其下内嵌该夹会话行——当前会话主题色高亮，其它行点击跳转官方会话，行尾「移出」按钮还原。
- **归档隐藏**：会话归入文件夹即从官方原生历史列表隐藏；原生历史始终只保留未收进文件夹的会话（避免点树内会话时官方滚回原位）。**例外**：原生「置顶」分组内的会话不隐藏，保证置顶列表始终完整。
- **「置顶」分组可折叠**：需在设置中开启子开关「置顶分组可折叠」（默认关）；开启后点击原生「置顶」标题即可收起/展开置顶会话列表（箭头与文件夹标题同款，展开态持久化；原生多选态下不响应）。关闭子开关即解绑并还原被折叠的会话。
- **原生多选态自动让位**：进入原生「选择对话」（多选）模式时，文件夹面板整区隐藏，把空间让给批量选择，退出后自动恢复。
- **分组操作走原生交互**：悬停会话三点 ⋯ →「移动到文件夹」→ 悬停展开文件夹列表（仿 Windows 级联子菜单，自动翻侧/夹紧视口），点击即归类；亦可「＋新建文件夹…」或「移出文件夹」。
- 会话标题旁附所属文件夹**彩色标签**（随浅/深主题配色）；分组数据（含展开态 `expanded`）存于独立键 `deepseek_folder_manager_data_v2`。
- **关闭开关**：还原全部被归档隐藏的原生会话行，移除树面板/彩色标签/注入菜单项与临时样式、清掉注入的 CSS 变量；再次开启不影响已保存的分组。

#### 2.6 对话导出为 Markdown / JSON（v5.0.0 新增，v5.2.0 增 JSON）
- **入口**：油猴菜单「导出对话」，或面板「📄 对话导出 → 开始选择」。
- **① 勾选态**：每条消息左上（提问）/ 右上（回答）角出现复选框，底部为通栏贴底 + 毛玻璃控制条；提供「全选 / 全选提问 / 全选AI回答 / 导出选中 (n) / 取消」，选中消息以不同配色高亮（用户消息右对齐气泡、AI 消息居中并带淡品牌底）；`Esc` 可随时退出。
- **② 长对话也能导全**：DeepSeek 用虚拟列表渲染，只渲染可视窗口内的消息、滚过去即被卸载。因此选择状态按**稳定键**（`vk:<虚拟列表项键>`）保存，并在消息可见的当下**就地快照**；点「全选」或「导出选中」时会逐步滚动整段对话完成采集（右上角显示扫描提示，结束后**恢复原滚动位置**）。实测连 4 条消息的短对话也存在 1 万余像素的窗口外内容。
- **③ 格式与弹窗**：第 1 步「选择导出内容」先选导出格式（Markdown / JSON），并决定是否「导出思考过程」（默认开）；选 Markdown 进第 2 步「选择内容模板」，每张模板卡带 **132px 缩微预览**（用真实选中内容按该模板版式渲染），点卡片即导出；可勾「记住我的选择」在下次预填。**JSON 没有模板层，点格式卡即导出。**
- **④ 9 套内容模板**：问答类为 原样输出 / 简洁对话 / 结构化笔记 / 知识文档 / 角色对话；只勾选提问时自动切换为 问题清单（纯文本）/ 问题清单（结构化）/ 问题大纲 / 问题卡片。
- **⑤ 转换质量**：自研 13 条规则的 DOM→Markdown 引擎，无第三方 Markdown 库。代码块围栏**自适应**（内容含 ``` 时自动加长）、表格按最大列数对齐补空并转义竖线、列表续行缩进对齐且正确嵌套、公式从 KaTeX 取回**原始 LaTeX** 还原为 `$…$` / `$$…$$`；剪枝用**白名单**（只留答案体与思考体），不依赖官网哈希类名。
- **⑥ 配套**：代码块停在「图表」Tab 时自动切回「代码」视图，避免丢代码；文件名规则为「兜底名 `DeepSeek对话` + 空格与 Windows 非法字符转下划线 + 截断 50 字 + 可选 `-YYYY-MM-DD-HH-mm`（默认开，避免重名覆盖）」，两种格式共用同一套规则。
- **⑦ JSON 结构**（v5.2.0）：输出 `{ schema: "deepseektool.export.v1", contentFormat: "markdown", title, url, exportedAt, messageCount, messages }`，`messages` 逐条为 `{ index, role, content, reasoning? }` —— `content` / `reasoning` 都是 Markdown 文本（保留代码块、表格、公式），思考过程**不再混在正文里**；2 空格缩进、UTF-8 无 BOM、MIME `application/json`。
- **隐私**：全部在本地完成，**对话内容不上传**。

#### 2.7 界面与输入增强
- **宽屏模式**（v5.7.0 三档）：消息内容区在官方默认宽度（实测 **840px**）之上加宽，面板可选三档——**标准 1000px（+160 / +19%）** / **较宽 1160px（+320）** / **最宽 1320px（+480）**，左右留白自动均分；开关默认关，档位默认「标准」（即旧版行为，升级后宽度不变）。
  - 档位是**绝对上限**而非相对增量：净增 = `min(可用宽, 档位值) − min(可用宽, 840)`。可用宽度不足以容纳 840 时，默认态本就没有留白可收，三档会趋同（实测 1102 视口、可用 753 时净增约 0；测量显示 1px，属取整/滚动条误差），非缺陷。
  - 切换开关，或宽屏开启时切换档位，都会让表格按新宽度重算列宽（见 `invalidateTableLayout`）。
- **Ctrl+Enter 发送**：默认关。开启后仅作用于对话输入框（textarea）：纯 Enter 被拦截为换行（不再发送），Ctrl/Cmd+Enter 以无修饰 Enter 重新触发官方发送逻辑，Shift+Enter 保持原生换行语义不做拦截；关闭即恢复官方 Enter 发送 / Shift+Enter 换行。

#### 2.8 代码块导出为图片（v5.1.0 新增）
- **入口**：代码块右上角「导出」按钮（位于「折叠 / 展开」按钮**左侧**）；点击打开样式弹窗，选好后一键导出。
- **样式选项（8 组）**：背景（8 套预设：5 渐变 + 浅灰 / 墨黑 / 透明）、窗口样式（macOS 红黄绿三点 / 无框）、代码底色（浅色底 / 深色底）、内边距（16–80px）、字号（12–18px）、行高（16–30px）、导出倍率（1x / 2x / 3x）、投影与行号。
- **明 / 暗底**：代码高亮**优先还原官网当前实测色**——导出时就地读页面上每个 `token` 元素的计算色，自动覆盖官网全部 token 类型（`tag` / `attr-name` / `attr-value` / `keyword` / `string` … 一个不漏）；底色与页面不一致时（如页面浅色、导出选深色底）改用自建 One Light / One Dark 色板兜底，避免明暗串味。可整体切明底 / 暗底。**不提供第三方语法主题**——本功能走「截取现有 DOM」路线，无法替换官网 `token` class 与配色的映射关系，故以「明 / 暗底」顶替「换主题」。
- **实时预览**：弹窗内用 **Shadow DOM** 隔离渲染缩微预览，切换任一选项即时刷新，不污染页面既有 `.token` 高亮规则。
- **输出**：下载 PNG（文件名含语言 + 时间戳，Windows 非法字符转下划线）或**复制图片到剪贴板**（`ClipboardItem`，需安全上下文；不可用时该按钮自动禁用——与官方「复制代码」的文字复制是两回事）。
- **记忆**：可记住上次的样式选择，下次打开自动预填。
- **实现要点**：克隆代码块 → 清洗（摘掉官方按钮 / 语言条 / 装饰 SVG / 折叠态样式）→ 在**离屏 iframe（`srcdoc`）** 内按自建样式重排 → `html2canvas({scale, backgroundColor:null})` 渲染为 Canvas → Blob。**全程不修改页面原 DOM**（沿用表格导出的「克隆 + 隔离」铁律；唯一例外是折叠态代码块仅在克隆副本上展开）。
- **隐私**：全部本地完成，代码内容不上传。

### 三、安装与使用

1. 安装脚本（Tampermonkey / ScriptCat）并访问任一 DeepSeek 对话页面。
2. 打开统一控制面板：点击**页面右下角的悬浮齿轮按钮**，或 **Tampermonkey / ScriptCat 菜单 →「设置」**。
3. 修改设置后**立即生效**、无需刷新；配置自动保存，下次打开页面保持。面板底部提供「恢复默认设置」一键还原。

> 各项设置的作用与默认值对照表、分功能操作步骤见 [scriptcat-description.md](scriptcat-description.md)。

### 四、兼容性

- 支持域名：`chat.deepseek.com`、`www.deepseek.com`、`deepseek.com`
- 依赖：`html2canvas@1.4.1`（`@require` 引入，用于表格与代码块的 PNG 导出）
- 基于 DeepSeek 当前 DOM 结构编写，若页面大版本更新可能导致部分功能失效。

### 六、版本历史
