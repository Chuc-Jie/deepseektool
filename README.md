## DeepSeek 功能增强工具箱 v4.9.1

> 面向 DeepSeek Web 端的增强用户脚本（Tampermonkey / ScriptCat 通用）。本文档面向开发者与维护者，记录模块行为、技术细节与版本历史；**安装使用、功能入口与设置项说明见 [scriptcat-description.md](scriptcat-description.md)**（即 ScriptCat 商店页描述，两者同源，改动功能时同步维护）。

### 一、脚本概述

为 DeepSeek 对话页提供统一控制面板的一站式增强：设置即时生效、无需刷新，配置自动保存。包含四大核心模块与若干附加开关：

1. **代码块折叠**：按行数阈值自动折叠，可自定义预览行数，手动展开不受后续加载重置。
2. **表格优化与导出**：修复表格宽度问题，可选的 PNG / CSV / Markdown 导出按钮（支持「持续显示」）。
3. **AI 思考过程自动折叠**：自动折叠「已思考」区域，支持模拟点击和 CSS 直接折叠两种模式。
4. **对话文件夹管理**（可选精辅，默认关）：左侧对话历史栏按「文件夹」做树形分组，会话 ⋯ 菜单直接移入/移出，收进文件夹即从原生列表隐藏；随官网浅/深色主题自适应。

> 附加项：宽屏模式（消息区扩展到全宽）、Ctrl+Enter 发送快捷键、表格主题/列宽多策略等，均在控制面板一页内完成，详见下文 2.2 / 2.5。

### 二、功能详情

#### 2.1 代码块折叠
- 在代码块右上角添加「折叠/展开」按钮（含箭头图标）。
- **自动折叠阈值**：代码行数超过设定值时自动折叠（默认 20 行，设为 0 则禁用）。
- **折叠预览行数**：折叠后保留前 N 行可见（默认 0 表示完全隐藏）。
- **状态保持**：用户手动展开的代码块不会因后续对话加载而自动折叠。

#### 2.2 表格优化与导出
- **样式修复（始终生效）**：表格宽度自适应、列宽分配、圆角边框、行悬停高亮。
- **列宽策略**：三种可选 —「均分」所有列等宽、「自适应」按内容比例分配、「均分+保护」等宽且不低于 80px（超出容器自动回落自适应）。
- **主题适配**：两种可选 —「自动适应」用半透明叠加色通吃浅/深色两种模式，「双模式」为浅色/深色各自优化配色。
- **导出按钮（可开关）**：表格右下角悬浮 📸（PNG）、📄（CSV）、📝（Markdown 一键复制），鼠标悬停显示；「持续显示」开启后常驻。PNG 依赖 `html2canvas` 且跟随当前主题配色；CSV 原生 UTF-8 BOM；Markdown 保留单元格内 `code`/加粗/斜体并转义 `|`。三种格式共用同一份「清洗副本」（`getCleanTableClone`）。

#### 2.3 AI 思考过程自动折叠
- 自动寻找「已思考」区域并折叠，避免页面过长。
- 两种折叠模式：
  - **模拟点击**（默认）：通过点击原生箭头折叠，保持与 DeepSeek 原生交互一致。
  - **CSS 直接折叠**：关闭模拟点击后使用，直接隐藏思考内容区域。

#### 2.4 对话文件夹管理（面板开关，默认关闭）
- 开启「🗂 启用文件夹分组」后，左侧「对话历史」栏出现文件夹面板（[文件夹]+[＋新建]，位于原生「置顶」分组之后），随会话历史整体滚动；面板头可整体收起/展开（状态持久化）。
- **树形就地展开**：文件夹行前空心图标点开/收起（展开态持久化），展开后其下内嵌该夹会话行——当前会话主题色高亮，其它行点击跳转官方会话，行尾「移出」按钮还原。
- **归档隐藏**：会话归入文件夹即从官方原生历史列表隐藏；原生历史始终只保留未收进文件夹的会话（避免点树内会话时官方滚回原位）。**例外**：原生「置顶」分组内的会话不隐藏，保证置顶列表始终完整。
- **「置顶」分组可折叠**：需在设置中开启子开关「置顶分组可折叠」（默认关）；开启后点击原生「置顶」标题即可收起/展开置顶会话列表（箭头与文件夹标题同款，展开态持久化；原生多选态下不响应）。关闭子开关即解绑并还原被折叠的会话。
- **原生多选态自动让位**：进入原生「选择对话」（多选）模式时，文件夹面板整区隐藏，把空间让给批量选择，退出后自动恢复。
- **分组操作走原生交互**：悬停会话三点 ⋯ →「移动到文件夹」→ 悬停展开文件夹列表（仿 Windows 级联子菜单，自动翻侧/夹紧视口），点击即归类；亦可「＋新建文件夹…」或「移出文件夹」。
- 会话标题旁附所属文件夹**彩色标签**（随浅/深主题配色）；分组数据（含展开态 `expanded`）存于独立键 `deepseek_folder_manager_data_v2`。
- **关闭开关**：还原全部被归档隐藏的原生会话行，移除树面板/彩色标签/注入菜单项与临时样式、清掉注入的 CSS 变量；再次开启不影响已保存的分组。

#### 2.5 界面与输入增强
- **宽屏模式**：消息内容区由官方默认宽度扩展至全宽（约 752→1000px），左右留白自动均分；开关默认关。
- **Ctrl+Enter 发送**：默认关。开启后仅作用于对话输入框（textarea）：纯 Enter 被拦截为换行（不再发送），Ctrl/Cmd+Enter 以无修饰 Enter 重新触发官方发送逻辑，Shift+Enter 保持原生换行语义不做拦截；关闭即恢复官方 Enter 发送 / Shift+Enter 换行。

### 三、安装与使用

1. 安装脚本（Tampermonkey / ScriptCat）并访问任一 DeepSeek 对话页面。
2. 点击 **Tampermonkey / ScriptCat 菜单 →「⚙️ 脚本设置」** 打开统一控制面板。
3. 修改设置后**立即生效**、无需刷新；配置自动保存，下次打开页面保持。面板底部提供「恢复默认设置」一键还原。

> 各项设置的作用与默认值对照表、分功能操作步骤见 [scriptcat-description.md](scriptcat-description.md)。

### 四、兼容性

- 支持域名：`chat.deepseek.com`、`www.deepseek.com`、`deepseek.com`
- 依赖：`html2canvas@1.4.1`（`@require` 引入，仅 PNG 导出使用）
- 基于 DeepSeek 当前 DOM 结构编写，若页面大版本更新可能导致部分功能失效。
